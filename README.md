# 3D Robot Office (demo)

A three.js scene where each running trading bot is a cartoon worker at a station, and closed trades are carried to a vault.
This public build uses generated demo data only — no real trading data.

- Toggle "80 年代主題" for the retro theme; "顛倒世界" switches to the dark mode.
- `?stats=1` shows fps / draw calls; `?replay=1` replays the last 7 days of deliveries.
